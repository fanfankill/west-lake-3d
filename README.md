# 西湖湖畔 · 3D 空镜

一个单文件网页：页面中央是可交互的西湖湖畔场景（湖面、九曲桥、重檐方亭、临水曲廊与水榭、林荫步道、长椅、园灯、石拱桥、月洞门），并沿湖补齐了一圈造景：苏堤六桥、白堤与断桥、孤山与平湖秋月、小瀛洲与三潭石塔、湖心亭、阮公墩、雷峰塔与净慈寺、北山街与保俶塔、城东天际线和湖上游船。场景是按比例压缩的写意组合，参照集贤亭与小瀛洲九曲桥的形制，并非实测复原。

## 目录

- `src/` 源码，按顺序拼接
  - `01-core.js` 工具、材质表、几何合并器（按“构件 × 材质”分桶）
  - `02-env.js` 渲染器、天空、湖水与倒影、飘落物、灯火光晕
  - `03-arch.js` 湖岸、曲桥、亭、廊、榭、拱桥、粉墙、长椅园灯
  - `04-flora.js` 草木、荷花、锦鲤、摇橹船与画舫、群山、苏堤、雷峰塔
  - `045-lake.js` 环湖造景：白堤断桥、孤山、小瀛洲、湖心亭、净慈寺、北山街、城市天际线
  - `05-state.js` 四季 / 天光 / 天气状态，相机，主循环
  - `06-ui.js` 景观·构件·材质数据，界面，漫步与环湖路线，沉浸模式，影片接口
  - `head.html` `body.html` 样式与界面结构
- `build.js` 生成 `dist/index.html`（发布用片段）和 `dist/west-lake.html`（可直接打开）
- `video/record.js` 逐帧录制漫步镜头；`video/music.py` 合成配乐
- `video/bgm.py` 合成网页用的长版配乐（约 104 秒），转成 `assets/bgm.mp3` 后由 `build.js` 以 base64 内嵌进页面
- `tools-page.js` `shot.js` `uitest.js` `lap-uitest.js` 本地截图与界面检查

## 使用

```bash
npm install          # three@0.128、playwright 用到的字体包
node build.js        # 生成 dist/
# 打开 dist/west-lake.html 即可（需联网加载 three.js 与字体）
```

录制影片（无头浏览器逐帧渲染，1920×1080 / 30 fps，36 秒：四季环绕 → 亭中日落 → 夜色灯影）：

```bash
node video/record.js video/out/parts          # 逐段输出 part*.mp4
python3 video/music.py video/out/music.wav     # 原创配乐《湖上四时》
# 合成：ffmpeg concat 拼接各段，再 -c:v copy 混入音轨
```

## 交互

- 拖动旋转，滚轮或双指缩放，右键 / Shift 拖动平移
- 左侧：景观（飞到取景点）、构件（聚焦、只看它、隐藏）、材质工艺（按材质高亮）
- 右侧：四季、白昼 / 夕照 / 入夜（入夜自动亮灯）、晴 / 烟雨（冬为落雪）、整体透明度
- 点湖面起涟漪，锦鲤循迹而来；入夜点湖面放荷灯
- “环湖一周”约四分半钟：从集贤亭出发，路线逐一贴近三潭印月、净慈寺、雷峰塔、苏堤两桥、阮公墩、湖心亭、孤山、平湖秋月、白堤断桥（最近 35–95 米）；镜头在到达前十来秒就转向景点并放慢，景名同时浮出，过了即隐去；四季随路程流转
- “沉浸模式”隐藏全部界面，只留画面；按 H 或 Esc、或点角上浮出的“显示界面”恢复
- “配乐”开关背景音乐（按 M 亦可）；开始环湖或进入沉浸模式时自动响起，手动关过就不再自动播放
- “湖畔漫步”沿曲桥入亭、从午后走到入夜；“四季流转”会缓慢环绕并逐季切换

## 画面做法

- 全部几何由程序生成，按“构件 × 材质”合并，材质可单独高亮
- 石、木、瓦、粉墙用世界坐标的噪声贴图做纹理与凹凸；树叶是带叶形透明贴图的面片，双面受光并带一点透光
- 锦鲤是三维鱼体（躯干、背鳍、胸腹鳍、臀鳍、叉尾），摆尾在顶点着色器里完成；鱼群有避让与最小间距约束，不会叠在一起
- 雷峰塔是八面五层楼阁式：两层石台基、每层平座回廊与栏杆、内外两圈朱柱、斗栱、门窗、铜瓦翘角和金色塔刹；保俶塔是六面七层砖塔：须弥座、叠涩出檐、券龛、铁刹
- 群山是细分的落地实体，山脚成林；殿堂有台基踏步、槅扇门、槛窗、额枋斗栱和脊饰，拱桥有望柱栏板
- 湖面为平面倒影 + 法线扰动 + 日月高光；影子只在光向或投影物变化时重画
- 影片镜头是解析式的连续运动（`src/06-ui.js` 的 `filmPose`），逐帧可重复
